# Bhrugu Varia — Portfolio

Motion-forward Next.js portfolio combining AI/automation work with the visual design practice behind _theilluminator and The LUM Campaign.

## Run

```bash
npm install
npm run dev
```

Run `npm run build` for a production build. Edit all project, experience, skill, and contact content in `data/content.ts`.

## Publish

Push the folder to GitHub and import the repository in Vercel. No environment variables are required.
